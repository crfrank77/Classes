# MAE 283A Approximate Identification and Control

MAE 283B  covers content ranging from approximate identification, estimation of models via closed-loop experiments, and closed-loop identification techniques. Estimation of model uncertainty, model invalidation techniques, and iterative techniques for model estimation and control design are explored as well.

# Final Project
The final project for this course had students analyze unique experimental data and build models to parametrize and control the output from each scenario. Within this project I analyzed simulated input and output data for an exothermic processing plant with an unknown controller, a microgrid with no controller, and a microgrid with an unknown controller. Utilizing parametric model estimates with output error, ARX, 2 stage methods, Box Jenkins, and spectral analysis I was able to perform a variety of tests and experiments utilizing the core concepts from the class to parametrize and control outputs from each respective data set. The report and code used in this project are contained in a single document this folder.
